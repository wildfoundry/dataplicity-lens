Roadmap

What we are considering next.

Lens grows from the problems we encounter while using it. This page lists ideas, not release commitments.

On this pageAvailable nowUnder consideration

Available now

The current suite covers processes, services, logs, storage, networking and system health on Linux and macOS. Each command can run interactively or produce plain-text and JSON output.

Under consideration

Possible additions include service dependency timing, log-rate baselines, directory growth, DNS checks and connection probes. We will prioritize work that proves useful in day-to-day support and operations.
