Terminal cockpit

One starting point for every signal.

The read-only cockpit summarizes host findings and opens process, service, log, storage, network and health views.

Graceful fallbacks

If a specialist executable is unavailable, the cockpit renders that view itself. Missing platform sources and permission limits remain visible as warnings, and terminal state is restored after errors or panics.

Read-only by design.

The cockpit never changes service, process, storage or network state.
