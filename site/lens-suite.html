Start with the overview

lens summarizes the host and opens each specialist view. Use it interactively or print the same information as plain text or JSON.

Specialist commands

01

lens-top

Processes, resource use, history and warnings.

02

lens-services

Service state, related processes and restarts.

03

lens-logs

Recent local logs with severity and service context.

04

lens-disk

Mounts, filesystems and storage use.

05

lens-net

06

lens-health

Warnings from all of the specialist checks.

Try it with sample data

shell 
lens --demo --plain
lens-net --demo --json
lens-health --demo

When data is unavailable

Lens uses the system tools and permissions available to the current user. If a check cannot run or a field cannot be read, the output includes a collection warning and keeps the data that was available.
