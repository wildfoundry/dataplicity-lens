Dataplicity Lens suite

All Lens tools are read-only and support Linux and macOS. They share a versioned snapshot model, deterministic demo mode, plain text and JSON contracts.

Commands

  • lens — cockpit and navigation
  • lens-top — processes
  • lens-services — systemd service state
  • lens-logs — journal messages
  • lens-disk — mounts and storage pressure
  • lens-net — interfaces, routes and listeners
  • lens-health — cross-domain findings
cargo build --release --workspace
lens --demo --plain
lens-net --demo --json

Unavailable platform interfaces become warnings; the tools never change system state. See architecture and lens-top.
