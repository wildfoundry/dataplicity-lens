Suite / lens-health
System checks

Review problems in one place.

See warnings from process, service, log, storage and network checks in one list, without repeated reports of the same problem.

On this pageUseWarningsA healthy result

Use

shell 
lens-health --plain
lens-health --filter disk
lens-health --demo --json

What each warning includes

Each warning includes its severity, the data that triggered it, the related process or service, and a suggested next check.

A healthy result

Healthy means that the checks with available source data found no problems. Any checks that could not run are listed separately as collection warnings.
