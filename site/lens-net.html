Networking

Interfaces, routes and listeners together.

Connect local network state back to the processes and services that own it.

On this pageUseContextPlatforms

Use

shell 
lens-net --plain
lens-net --filter 443
lens-net --demo --json

Processes behind listening sockets

Where the operating system provides an owner PID, Lens links a listening socket to its process and service. It also reports down interfaces and a missing default route.

Linux and macOS sources

Lens uses the networking tools provided by each platform. Missing tools or restricted owner details appear as collection warnings.
