Dependency direction

The model owns canonical user-facing types. Platform collection produces the model; history derives rates; diagnostics consumes snapshots; output and UI render the same structures.

No presentation crate reads /proc. No collector emits terminal strings. A future tool earns a crate only when it introduces a durable responsibility.

Process identity survives PID reuse.

A process key combines PID and kernel start ticks. History joins only when both match. A disappeared process is skipped; a broken parent reference is bounded; a cycle cannot trap tree rendering.

rust
ProcessKey {
  pid: 8421,
  start_time_ticks: 783_204_119,
}

Read Linux directly, carefully.

The collector uses local read-only kernel and operating-system interfaces. Required host files produce a clear top-level error. Optional process detail can be absent without invalidating the sample.

  • /proc/stat, meminfo, loadavg and uptime
  • /proc/[pid]/stat, status, cmdline, io, cgroup, fd and exe
  • Hostname, kernel release, OS release and user mapping
Environment variables are deliberately not collected.

Normal user permissions remain in force and missing fields remain visible as missing.

Bounded session history.

CPU uses process tick deltas relative to host tick deltas. I/O uses counter deltas over measured time. Buffers are bounded, counters saturate on decreases and v0.1.0 writes no persistent history.

Evidence before diagnosis.

A finding has an identifier, severity, evidence, related entities and suggested actions. The engine is deterministic and uses cautious wording when evidence is suggestive rather than conclusive.

No network calls. No AI model.

Findings come from the same local snapshot shown to the operator.

Deliberate boundaries

  • Linux only in v0.1.0
  • Read-only operation
  • No daemon, cloud dependency or Dataplicity account
  • No telemetry
  • No plugins until shared contracts are proven
  • No placeholder binaries for roadmap tools

These are product decisions, not missing footnotes. They keep the first release understandable and trustworthy.
