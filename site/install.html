Install Lens.

Use Homebrew on macOS, a release package on Linux or Raspberry Pi OS, or build the complete suite from source.

Prerequisites

The local installer supports Apple Silicon and Intel Macs. Install Homebrew, Git and Apple's command-line tools. If the command-line tools are missing, run:

shell 
xcode-select --install

Install and test with Homebrew

shell 
git clone https://github.com/wildfoundry/dataplicity-lens.git
cd dataplicity-lens
scripts/test-homebrew-local.sh --keep

The script makes a local source archive, installs the committed formula, checks sample output from every command, and checks native macOS process collection. Homebrew supplies Rust as a build-only dependency, so the first run can take several minutes.

Try the suite

shell 
lens --demo
lens-top --once
lens-services
lens-logs --since "1 hour ago"
lens-disk
lens-net
lens-health --json

Run lens-top with no flags for the interactive explorer; press q to exit. Run Lens as your normal account, not with sudo.

macOS privacy controls

macOS may restrict some unified-log and per-process details. Lens preserves normal permissions and reports unavailable fields as warnings rather than failing the entire snapshot or requesting elevated access.

Raspberry Pi OS

Both 64-bit and 32-bit Raspberry Pi OS are supported. Run dpkg --print-architecture. Install the arm64 Debian package when it prints arm64, or the armhf package when it prints armhf.

shell 
dpkg --print-architecture
sudo apt install ./dataplicity-lens_0.2.0_armhf.deb
lens-top --once

The 32-bit package uses an ARMv6 hard-float build so it can run across Raspberry Pi models using 32-bit Raspberry Pi OS.

Remove the test installation

shell 
brew uninstall dataplicity-lens
brew untap local/dataplicity-lens-test

Omit --keep from the installer when you want it to clean up automatically after testing.

Build directly from source

shell 
cargo build --release --locked --workspace
./target/release/lens --demo --plain
