# Code of conduct

We want Dataplicity Lens to be a technically serious and welcoming project.

Be direct without being demeaning. Critique code and decisions, not people. Assume good faith, explain
trade-offs, and make room for contributors with different levels of Linux and Rust experience.
Harassment, discrimination, threats, doxxing and sustained disruptive behaviour are not accepted.

Project maintainers may edit or remove contributions and communications that violate these rules and
may temporarily or permanently restrict participation. Report conduct concerns privately to the
maintainers through the repository's security/contact channels.
