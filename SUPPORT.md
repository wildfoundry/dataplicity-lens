# Getting help

For installation and usage, start with the [Lens documentation](https://lens.dataplicity.com/) and
[`docs/INSTALLING.md`](docs/INSTALLING.md).

If those do not answer your question, open a [help
issue](https://github.com/wildfoundry/dataplicity-lens/issues/new?template=help.yml). Include your Lens
version, operating system, architecture and the command you ran. You can print the build details with:

```sh
lens-top --version
```

The issue tracker is also the support route for reproducible bugs and specific feature requests.
Remove hostnames, usernames, IP addresses, log contents and other sensitive system information before
posting output or screenshots.

Do not report suspected vulnerabilities in an issue or discussion. Follow [`SECURITY.md`](SECURITY.md)
to send the report privately.

Lens support is handled in this repository. There is no separate support email or telephone line.
